## About Me

- Master of Electronics Science with a strong focus on embedded systems.
- Working on low-level device drivers, peripheral interfaces, bootloaders, and RTOS-based firmware.
- Experienced with STM32, ESP32, C, C++, Python, serial communication, and embedded debugging.
- Currently strengthening skills in Embedded Linux, Yocto, and production-grade firmware workflows.
- Based in Pune, India.
